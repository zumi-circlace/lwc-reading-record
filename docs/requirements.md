# 読書記録アプリ 要件定義

この文書は、実装の正本である。当初メモ（[memo.md](memo.md)）から QA で固めた内容を、画面・データ・権限・対象外まで読み物として整理している。

## このフェーズで覚えること

Salesforce アプリは「画面（LWC）」「データ（オブジェクト）」「権限（OWD / 権限セット）」「外部連携（Named Credential + Apex）」が別レイヤである。要件では、どれを自分たちで作り、どれを標準機能に任せるかを先に決める。

---

## 1. 目的

読了した本を記録し、月別・カテゴリ別に可視化する。自分で日常使いしつつ、クライアントには次を見せられるようにする。

- 要件定義からソース駆動デプロイまでの一連
- マスタ（本）とトランザクション（読書記録）の関係設計
- 組織の共有設定と Apex のセキュリティ（`with sharing` / `USER_MODE`）
- 外部 API 連携（Named Credential）

## 2. 利用者と利用場所

| 項目 | 決定 |
| --- | --- |
| 主利用者 | 自分。家族には権限セットを渡せば使える |
| 可視性 | 読書記録は所有者以外に見えない（デモでもこれを再現する） |
| 登録 | スマホ（Salesforce モバイルアプリ）。バーコードはここが本領 |
| ダッシュボード | PC ブラウザ |
| 入れ物 | Lightning アプリ（カスタムタブ）。Experience Cloud は対象外 |

## 3. 機能一覧

### 3.1 登録（LWC）

3 タブ。入力経路だけ違い、確認〜保存は共通コンポーネント。

1. **カメラ**  
   バーコード → ISBN → openBD（0〜1件）→ 確認画面で編集 → 保存。  
   ブラウザでは動かない。PC では非対応メッセージを出す。
2. **検索**  
   ISBN でもタイトルでも同じ入力枠。  
   - 数字（ISBN）→ openBD  
   - それ以外 → Google Books（最大 10 件）から 1 冊選択  
   選択後は同じ確認画面。
3. **完全手打ち**  
   API ミス・同人誌・古い本。タイトル・カテゴリ・著者などを手入力して確認〜保存。

共通ルール:

- 即保存しない。確認画面で直してから保存する。
- 検索ゼロ件はエラーを出し、完全手打ちタブへ誘導する。
- ISBN-13 を正規形とする。ISBN-10 は変換してから検索する。
- 読了日のデフォルトは今日。
- 必須は **本のタイトル** と **読了日**。ISBN・カテゴリ・感想は任意。

### 3.2 再読

同じ本（同じ ISBN の `Book__c`）を再び読んだら、新しい `ReadingLog__c` を追加する。  
保存前に「自分の既存記録」があれば警告し、既存を開くか、もう 1 件追加するかを選ばせる。拒否はしない。

### 3.3 一覧・編集・削除

- アプリ内一覧: 自分の記録、読了日降順、タイトルで絞り込み。表紙・タイトルは本マスタから表示する。
- 標準リストビューも用意する。
- 編集・削除は一覧または標準レコードページ。記録を消しても本マスタは残す。

### 3.4 可視化

標準レポート + Lightning ダッシュボード。

- 月別の記録数
- カテゴリ内訳（本の `Category__c`）

LWC 製チャートは今はやらない。

## 4. 画面一覧

| 画面 | 種類 | 役割 |
| --- | --- | --- |
| 読書を記録 | LWC タブ | カメラ / 検索 / 手打ち / 確認 |
| 記録一覧 | LWC タブ | 自分の記録の検索・参照・削除。編集は標準ページへ |
| 本 | 標準タブ + レイアウト | 書誌マスタの参照・手修正 |
| 読書記録 | 標準タブ + レイアウト | 記録の参照・編集 |
| ダッシュボード | 標準ダッシュボード | 月別冊数・カテゴリ内訳 |

## 5. データ概要

2 階層。詳細は [data-model.md](data-model.md)。

- `Book__c` … 書誌（タイトル、ISBN、著者、出版社、出版年、表紙 URL、カテゴリ）
- `ReadingLog__c` … 読了日、感想、`Book__c` への Lookup

表紙は API の画像 URL を保存して表示する（Files には置かない）。

### カテゴリ（選択リスト）

QA で未列挙だったため、初回実装では次で確定する。追加・改名は選択リスト値の変更だけでよい。

- 小説
- ビジネス
- 技術書
- 趣味
- 漫画
- その他

## 6. 外部 API

| 用途 | API | 認証 |
| --- | --- | --- |
| ISBN 引き（0〜1件） | openBD `GET /v1/get?isbn=` | 不要。Named Credential `OpenBD` |
| タイトル検索（複数件） | Google Books `GET /books/v1/volumes` | API キー推奨。Named Credential `GoogleBooks` + Custom Metadata |

openBD は ISBN 専用で、タイトル検索エンドポイントはない。

## 7. セキュリティ

詳細は [security-design.md](security-design.md)。

- `ReadingLog__c` OWD: 非公開
- `Book__c` OWD: 公開（参照のみ）。作成は権限セットで付与（家族で書誌を再利用）
- 権限は権限セット `ReadingAppUser` のみ（プロファイルは触らない）
- Apex は `with sharing`（または `inherited sharing`）+ DML/SOQL は `USER_MODE`

## 8. 非機能

- 開発・本番相当は既存 Developer Edition。ソースは Git 管理。
- 復旧は `sf project deploy start` + 権限セット割り当て + 任意で CSV 投入。
- Apex テストカバレッジ 75% 以上。`SeeAllData=false`。
- CI（GitHub Actions）は今回やらない。

## 9. 対象外

Experience Cloud、星評価、読書中ステータス、表紙の Files 保存、LWC チャート、GitHub Actions、LWC Jest（任意）。  
ISBN なし手打ち本のあいまい名寄せもしない（毎回新しい `Book__c`）。

## 10. 環境

既存 Developer Edition にデプロイする。Named Credential と Google API キーは組織側の設定が必要（手順は README）。
